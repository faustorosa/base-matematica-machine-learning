# Base Matemática para Machine Learning

> 🚧 **Projeto em construção**
>
> Este repositório está sendo desenvolvido progressivamente conforme avanço nos estudos, revisões e implementações dos conteúdos.

Uma coleção de notebooks voltada ao estudo dos fundamentos matemáticos necessários para compreender com mais profundidade **Machine Learning, Ciência de Dados, Otimização e Computação Científica**.

A proposta não é substituir livros tradicionais de Matemática nem criar, neste momento, um curso completo.

O objetivo é construir uma ponte entre:

$$
\boxed{
\text{Matemática}
\longrightarrow
\text{Computação}
\longrightarrow
\text{Machine Learning}
}
$$

---

## 📚 Metodologia

Sempre que possível, os notebooks seguem a sequência:

**Conceito → Interpretação → Cálculo manual → Python → Experimento → Aplicação**

A ideia é evitar dois extremos comuns:

* utilizar bibliotecas matemáticas sem compreender o que acontece por trás;
* estudar a teoria sem visualizar como ela aparece em problemas computacionais.

Python entra como ferramenta para **confirmar, experimentar, visualizar e aplicar** a Matemática — e não como substituto para sua compreensão.

## 🎯 Objetivo do projeto

Este projeto nasceu durante um processo de revisão e aprofundamento da minha própria base matemática.

A intenção é registrar esse caminho de forma organizada e, ao mesmo tempo, disponibilizar gratuitamente um material que possa ajudar outras pessoas de **Dados, Inteligência Artificial e áreas relacionadas** a compreender melhor a Matemática existente por trás das ferramentas.

O repositório continuará sendo atualizado conforme novos tópicos forem estudados, revisados e implementados.
